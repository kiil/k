Planlægning med Nushell, AI og khal

10. december 2024·338 ord·2 minutter
Hvad er kunstig intelligens Nushell AIChat Khal

Sådan så det ark ud jeg havde fået i postkassen.

Jeg tog et billede af det med min mobil og overførte det til min computer.

Så brugte jeg aichat til via OpenAIs api at analysere billedet:

aichat -f foto.png "giv mig en simpel json liste
                    over nævnte datoer medtag kun
                    begyndelsesdatoer og formater
                    som YYYY-MM-DD"

Og fik svaret:

{
  "datoer": [
    "2025-01-25",
    "2025-02-22",
    "2025-03-29",
    "2025-04-26",
    "2025-05-31",
    "2025-06-28",
    "2025-07-26",
    "2025-08-30",
    "2025-09-27",
    "2025-10-25",
    "2025-11-29",
    "2025-12-27"
  ]
}

Det kopierer jeg så ind i Nushell der taler flydende json’sk:

wl-paste | from json | get datoer

╭────┬────────────╮
│  0 │ 2025-01-25 │
│  1 │ 2025-02-22 │
│  2 │ 2025-03-29 │
│  3 │ 2025-04-26 │
│  4 │ 2025-05-31 │
│  5 │ 2025-06-28 │
│  6 │ 2025-07-26 │
│  7 │ 2025-08-30 │
│  8 │ 2025-09-27 │
│  9 │ 2025-10-25 │
│ 10 │ 2025-11-29 │
│ 11 │ 2025-12-27 │
╰────┴────────────╯

Tjekker lige hurtigt at datoerne stemmer.

Og nu kan jeg lave et lille script som gemmer disse datoer i min kalender:

wl-paste | from json | get datoer | each { khal new $in Storskrald }

Og for lige at være sikker på at de rent faktisk er gemt, så søger jeg i kalenderen:

khal search Storskrald

2025-01-25-2025-01-25 Storskrald
2025-02-22-2025-02-22 Storskrald
2025-03-29-2025-03-29 Storskrald
2025-04-26-2025-04-26 Storskrald
2025-05-31-2025-05-31 Storskrald
2025-06-28-2025-06-28 Storskrald
2025-07-26-2025-07-26 Storskrald
2025-08-30-2025-08-30 Storskrald
2025-09-27-2025-09-27 Storskrald
2025-10-25-2025-10-25 Storskrald
2025-11-29-2025-11-29 Storskrald
2025-12-27-2025-12-27 Storskrald

Det tog mig et minut.

Jeg tror det ville have taget mig i hvert fald tre gange længere tid at taste hver dato ind for sig.

Og jeg har brugt 15 gange mere tid på at skrive et blogindlæg om det, men jeg håber nogen kan bruge det til noget.

Det er et kreativt eksempel på hvordan kunstig intelligens kan lette hverdagen og sammen med Nushell løse repetitive opgaver hurtigt og effektivt.

Bemærk at den kunstige intelligens selv regner året ud, ud fra overskriften velsagtens.

Kunstig intelligens kommer til at overtage et utal af den slags opgaver. Det er allerede i gang.
